##############################################
Molecular Dynamics Core Package Documentation
##############################################

The Molecular Dynamics Core package **orionmdcore**
is not a "Floe Package" *per se*, in that it does not provide any actual floes.
Rather, this package provides the ingredients,
in the form of Orion cubes (modules), from which to construct
Orion floes capable of running a wide variety of
routine MD simulations in Orion.
